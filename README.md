# ESP32-TinyML-Smart-Light-Classifier
Capstone TinyML integration prototype on ESP32. Combines WiFi web server, LDR light sensor, on-device TFLite Micro classification, SSD1306 OLED display, and automated LED control. Predicts ambient light classes, auto-switches night lighting on Dark prediction, and serves real-time JSON web dashboard. Simulated on Wokwi.
